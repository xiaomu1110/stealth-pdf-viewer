# Stealth PDF Viewer (工位摸鱼考公刷题神器)

> **专为工位打工人、备考考公/考研/考证设计的极致隐蔽 PDF 涂鸦与做题编辑器。**  
> 深度融入 VS Code，零可疑 UI，双向真实文件老板键，深色代码黑防窥，做题笔迹无损保存。

---

## 🌟 核心特色

### 1. 深度融入 VS Code 原生界面
- **默认打开 PDF**：安装后，资源管理器中直接左键点击任意 `.pdf` 题册，默认使用本插件打开。
- **编辑区零暴露 UI**：移除了所有突兀的网页顶栏、浮动调色盘。整个编辑区仅呈现沉浸式试卷内容，外观完全与代码编辑器融为一体。
- **功能隐蔽藏于底部状态栏**：翻页、画笔、荧光笔、橡皮、颜色切换、保存等按钮全部融入 VS Code 右下角状态栏（与 `UTF-8`、`Git 分支` 等开发指标并列）。
- **切出自动隐匿**：切换到普通代码标签页时，题册状态栏按钮**全自动消失**；切回题册时无缝恢复。

### 2. 双向真实代码老板键 (`Esc`)
- **题册内按 `Esc`**：瞬间自动检索并跳转到当前目录或工作区下的真实代码文件（如 `.go`、`.py`、`.md`、`.sql` 等）。路过同事或领导看到的 100% 是真实工程代码。
- **代码中再按 `Esc`**（或点击右下角 `$(chevron-left) 回到题册`）：立即无缝切回题册，精确回到上次所读页面与笔记。

### 3. 考公刷题涂鸦与无损保存
- **专业做题笔刷**：红笔（改卷选答案）、蓝笔、绿笔、黄色荧光笔（划题干关键信息）、极隐蔽代码灰。
- **细度可调（最小 1px）**：点击状态栏粗细或按 `[` / `]` 调节，支持 1px 极细微线。
- **系统原生指针**：告别突兀的绘图十字准星，全程使用操作系统默认标准鼠标指针。
- **原笔迹嵌入保存**：按 `Ctrl + S` 或点击状态栏「存」，将涂鸦笔记原样合成写回 PDF 文件，永不丢失做题记录。

### 4. 工位防窥「代码黑」模式
- 一键开启深色反转滤镜，白底黑字的题册瞬间变为 VS Code 原生 `#1e1e1e` 深色代码背景，黑字变为浅灰代码文字。走道外侧看如同在阅读开发规范或长篇技术文档。

### 5. 进度与状态持久缓存
- 基于 VS Code `globalState` 针对每个 PDF 路径独立持久化。重新打开题册自动定位到上次阅读的页码，恢复画笔、粗细与滤镜，无缝继续刷题。

### 6. 双模支持：VS Code 插件 + 独立网页版
- 除了 VS Code 扩展外，根目录提供 `index.html` 与 `启动刷题.bat`，在未安装 VS Code 的电脑上双击即可直接在 Edge / Chrome 中离线免安装使用。

## ⌨️ 快捷键指南

| 快捷键 | 功能说明 |
|---|---|
| **`Esc`** / **`` ` ``** | **老板键**（在题册与真实代码之间双向瞬切） |
| **`A`** / **`D`** 或 **`←`** / **`→`** | 上一页 / 下一页 |
| **`1`** / **`2`** / **`3`** | 切换画笔 / 荧光划线笔 / 橡皮擦 |
| **`[`** / **`]`** | 画笔粗细减细 / 增粗（最小 1px） |
| **`Ctrl + Z`** | 撤销上一步笔画 |
| **`Ctrl + S`** | 实时保存做题批注写回原 PDF |

## 📦 安装方式

### 方式 A：通过 GitHub Releases 下载安装（推荐）
1. 在 [Releases 页面](../../releases) 下载最新的 `stealth-pdf-viewer-x.x.x.vsix` 文件。
2. 打开 VS Code，按 `Ctrl + Shift + X` 打开插件市场，点击右上角 `...`（更多菜单）。
3. 选择 **「从 VSIX 安装... (Install from VSIX...)」**，选取下载的文件。
4. 按 `Ctrl + Shift + P` 输入 `Developer: Reload Window` 重载窗口即可完成生效。

### 方式 B：终端一键安装
```bash
code --install-extension stealth-pdf-viewer-1.2.0.vsix
```
